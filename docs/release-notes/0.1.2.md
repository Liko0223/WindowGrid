# WindowGrid 0.1.2

- Adds an optional Auto Repair Layout mode that checks the current desktop every 10 seconds and only repairs the layout after windows have stayed stable.
- Keeps automatic layout repair conservative with a 5-second stability delay and a 45-second cooldown after each repair.
- Pauses automatic repair while dragging windows, holding the snap modifier, or editing layouts.
- Removes the desktop-switch toast that appeared when changing macOS desktops.
